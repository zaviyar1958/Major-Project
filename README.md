# NAAC Portal - Major Project

This repository contains both the Backend and Frontend for the NAAC Accreditation Management System.

## Project Structure

```text
naac/
├── naac_backend/       # Express.js / Node.js & Prisma backend API
├── naac_frontend/      # React + Vite frontend application
└── README.md
```

## Getting Started

### 1. Backend Setup
```bash
cd naac_backend
npm install
# Copy .env.example to .env and configure your variables
cp .env.example .env
npm run dev
```

### 2. Frontend Setup
```bash
cd naac_frontend
npm install
# Copy .env.example to .env and configure your variables
cp .env.example .env
npm run dev
```
